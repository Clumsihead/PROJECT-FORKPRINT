# AI

Forkprint is AI-enhanced, not AI-dependent.

## Rule

If every AI provider is removed, the app must still function normally.

## Abstraction

`AiMemoryProvider` exposes optional enrichment capabilities. The default implementation is `NoOpAiMemoryProvider`.

Future NVIDIA-backed implementations may add:

- Natural language search
- Weekly summaries
- Taste analysis
- Food stories
- Trip summaries
- Recommendations

## Privacy

AI requests must be explicit, minimal, and understandable to the user. Local summaries/search should be preferred when sufficient.
